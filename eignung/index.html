Passt eine Ausschreibung im Ausland zu Ihnen?

Sechs Fragen, eine ehrliche Einschätzung. Die Antworten bleiben in Ihrem Browser.

1. Haben Sie im Land des Käufers eine eigene Niederlassung, einen Händler oder einen Exklusivvertreter?
2. Zeigt Ihre Website genau das verlangte Produkt oder Modell?
3. Können Sie Lieferungen dieser Grösse mit Referenzen belegen?
4. Können Sie Montage, Service oder Garantie im Land leisten – selbst oder mit einem Partner?
5. Bleiben bis zur Frist noch mindestens vier Wochen?
6. Können Sie Unterlagen auf Englisch liefern und eine Übersetzung bezahlen, falls verlangt?
